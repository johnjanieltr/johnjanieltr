## Proyectos destacados

- **[Secure Password Generator](https://github.com/johnjanieltr/secure-password-generator)**: generador de contraseñas que funciona 100 % en el navegador, con Web Crypto API, mezcla Fisher–Yates, Content-Security-Policy estricta e interfaz en 4 idiomas. JavaScript (ES modules) + Tailwind CSS v4. [Demo](https://secure-password-generator-b96.pages.dev/)
- **[Todo app](https://github.com/johnjanieltr/todo-app)**: React + Vite + Tailwind CSS, con drag & drop (dnd-kit), filtros, modo oscuro y persistencia. [Demo](https://johnjanieltr.github.io/todo-app)
- **[Oral Dent](https://oraldent.freedev.app/)**: landing page para una clínica dental en WordPress, con prototipo previo en Claude Design y desarrollo con Claude Code.
- **[Manage landing page](https://github.com/johnjanieltr/manage-landing-page)**: HTML, CSS (BEM, mobile-first) y JavaScript. [Demo](https://johnjanieltr.github.io/manage-landing-page)
